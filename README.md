## Exercício E2E Cypress - EBAC

- Projeto do módulo 12 de Engenharia de Qualidade de Software.

### O que foi utilizado
- Cypress
- Page Objects
- Faker (para gerar dados na área de checkout)

### Cenário automatizado
- Login do usuário
- Escolha de produtos
- Adição dos produtos ao carrinho
- Preenchimento do checkout
- Validação do pedido finalizado com sucesso
